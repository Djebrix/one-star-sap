A single one-line 1-star review, written by a houseplant about its human owner — for the [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty on make.fun.

## The line

> One star. He waters me like he's apologising for a murder, then stashes me in the dark corner like I'm the evidence. I wrote this in sap, so you know I mean it.

## Run

```sh
python3 main.py
```

Writes the line to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output`). Stdlib only, no network, deterministic — two runs produce byte-identical output.
